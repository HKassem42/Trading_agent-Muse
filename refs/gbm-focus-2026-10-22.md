## What was tested

Kass pasted an external top-10 feature ranking and green-lit a test
("try these ones… whatever you want to do"), and asked whether SMOTE
would make the bot more aggressive. Item 1 of his paste was cut off —
its surviving description is a raw-volume move-confirmation feature,
covered here by **two** columns, `Volume` and `On-Balance Volume
(OBV)`, which share his rank 1. The focus set is therefore 11
features: Volume, OBV, Force Index, Elder Force Index (EFI),
Historical Volatility (HV), Mass Index (MI), Bollinger BandWidth,
Connors RSI (CRSI), Accumulative Swing Index (ASI), Ultimate
Oscillator (UO), Choppiness Index (CHOP) — taken as RAW values from
the real BTC matrix (`data/timeseries_matrix/btc_usd_1h_matrix.csv`,
16,735 rows, BTC/USD 1h, 2024-11-23 → 2026-10-21; labels computed from
next-candle return, ±0.3% fee band; BUY 2,915 / HOLD 10,976 / SHORT
2,844).

Learner: LightGBM multiclass (3-class), one fixed hyperparameter set
for every arm (300 trees, lr 0.05, 31 leaves, min-child 40, row/col
subsample 0.9, λ=1.0, seed 42) — chosen once and never tuned against
the duel windows.

| Arm | Design |
|---|---|
| A | Focus-11, plain |
| B | Focus-11, balanced class weights (inverse class frequency) |
| C | Focus-11, SMOTE inside each training fold only (stacker recipe: scaler fit on the fold's train rows → SMOTE → model; validation never resampled, never scaled into) |
| D | All 60 matrix feature columns (Volume included), class-weighted — context arm: focused list vs kitchen sink |

**Force Index ↔ EFI correlation: 0.517** — the suspected
near-duplicate pair is not one. Force Index is the raw 1-bar Elder
form (volume × Δclose); EFI is its EMA(13) smoothing, and on a series
this noise-dominated the smoothing decorrelates them substantially.
Both stayed in the focus set as Kass listed them.

### Flags on the two "passes" — read before celebrating either

- **Neither pass made money.** Arms A and D pass the gate *formula*
  only because the formula compares against a champion that lost
  $4,485 on these windows. In absolute terms A lost $175 and D lost
  $3,178, and both lost to doing nothing but holding BTC (+$718).
- **Arm A is the near-silent case.** Six round trips in 30 trading
  days, and in window 2 it placed **zero trades** (score 0.00 — it
  "won" that window by sitting out while the champion lost). Six
  trips clears the experiment's pre-registered activity floor (≥3),
  so it is not labelled vacuous — but it sits squarely in the gray
  zone of the gate's known no-activity-floor flaw, the same flaw that
  made HA-Seq's 0-trade run display as a pass. Kass's decision on
  that gate rule is still pending; under any stricter floor (e.g.
  ≥1 trip/day) arm A would not count as a pass.
- Arm D's activity is real (45 trips) but its P&L is the second-worst
  of the four arms; more features did not rescue it.

### The SMOTE question, answered with money

Among the three focus arms, aggression and losses rise together:
plain A barely trades (6 trips) and loses $175; SMOTE C trades 37
times and loses $6,208; class-weighted B trades most (66) and loses
most ($8,432). SMOTE did exactly what it promises mechanically —
balanced classes, more BUY/SHORT calls, no HOLD-collapse — and the
extra activity converted directly into extra losses after fees and
stops. **SMOTE is not an aggression upgrade on this data; it is a
loss amplifier**, because the underlying calls carry no edge for it
to amplify. Class weights have the same disease in a stronger dose.

## Verdicts in plain words

- **Arm A (focus-11, plain):** Learned to mostly shut up. Lost $175
  where the champion lost $4,485 — by trading 6 times in a month,
  including one window of total silence. A formula pass that proves
  restraint, not edge. Not a challenger.
- **Arm B (focus-11, class weights):** The aggression Kass asked
  about, at full dose — and the worst result on the board: −$8,432,
  0/3 windows. FAIL.
- **Arm C (focus-11, SMOTE):** SMOTE worked mechanically and failed
  economically: −$6,208, 1/3 windows. FAIL. The SMOTE question is
  answered: on this data it amplifies losses, not edge.
- **Arm D (all-60, weighted):** A formula pass with real activity
  (45 trips) and a −$3,178 P&L. The kitchen sink beat the champion
  and lost to buy-and-hold. Not a challenger.
- **Overall:** The focus list contains exactly one feature with
  measurable solo value (raw Volume), and no combination of these
  11 — or of all 60 — turned into money under honest grading. This
  is the fourth independent null on 1h BTC (TA stacker, PPO,
  HA-sequence, A-Z screen) and the first with gradient boosting on
  Kass's own feature list. All four arms are registered in the lab
  (runs 21–24, promoted=0); the park holds.
