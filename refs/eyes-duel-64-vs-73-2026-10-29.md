# Eyes Duel — Run 64 eyes vs Run 73 eyes (2026-10-29)

Kass asked whether any dashboard models had done well in training but
never been duelled. Audit of all 79 registry runs: every PPO was
duelled except the pre-registered walk-forward-only diagnostics
47/48/49/53 (no trained brain exists for them; they FAILED their WF

and served as Book #2's first eyes, but was never money-duelled as
eyes. Kass approved this duel 2026-10-29 ("run it for fun").

  `scripts/duel_eyes_64_vs_73.py`; raw results

## Verdict

Run 73's eyes genuinely see better tonight (+2.27 pts accuracy, and
they vote very differently — 438 vs 324 up-calls), yet run 44's brain
made **the same money trades with either eyes**: identical P&L to
the cent in all three windows. The only action-mix difference is a
few hold↔sell flips on flat positions (no-ops) in the last window.
The PPO's decisions are dominated by its 21 features + portfolio
state; the single P(up) input does not flip argmax often enough to
matter at these vote differences.

Corroborated live the same day: Book #1 (run 40 eyes) and Book #2
(run 73 eyes) covered their shorts on the same candle at the same
price ($78,890.57, 2026-10-29 21:00 UTC).

Lesson: for THIS brain, stacker exam gains do not convert to P&L.
Crowns decided on accuracy alone overstate what an eyes upgrade buys
the money side; a pair duel is the only test that prices the eyes.
Lab only — no promotion, seat, or shadow change follows from this.
